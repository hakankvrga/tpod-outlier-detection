# tpod-outlier-detection
TPOD algoritması Python implementasyonu ve karşılaştırmalı analiz
## Kullanım
1. Repoyu klonla: git clone https://github.com/hakankvrga/tpod-outlier-detection
2. creditcard.csv dosyasını Kaggle'dan indirip klasöre ekle(https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
3. TPOD_Proje.ipynb dosyasını VSCode'da aç ve çalıştır

## Gereksinimler
pip install numpy pandas scikit-learn pyod matplotlib
